# XDC-Plus demo clips

This folder holds everything needed to rebuild the two demo clips shipped with
the XDC-Plus release:

| Clip | Screen mode | Picture | Frame rate | Length | Audio |
| --- | --- | --- | --- | --- | --- |
| `DEMO5.XDV` | 5 | 160x100, 16 colours (CGA/EGA/VGA text-mode trick) | 30 fps | 60 s, 1800 frames | 8-bit mono, 11040 Hz |
| `DEMO6.XDV` | 6 | 320x200, 16 colours (EGA/VGA BIOS mode 0Dh) | 15 fps | 60.4 s, 906 frames | 8-bit mono, 11040 Hz |

Every picture and every note of music is generated by the Python scripts here.
There is no video footage and no sampled audio.

## Files

| File | Purpose |
| --- | --- |
| `demo5.py` | Draws the 1800 DEMO5 frames and writes the music, the BMPs and `DEMO5.SCR` |
| `demo6.py` | Draws the 900 DEMO6 frames and the music, then calls `plan6.py` |
| `plan6.py` | Fits each DEMO6 frame into a per-frame byte budget (see below), writes the BMPs, the WAV and `DEMO6.SCR` |
| `music.py` | Small procedural chiptune synthesizer (pulse leads, stepped triangle bass, noise drums, arpeggios) |
| `font5x7.py` | Hand-drawn 5x7 pixel font and sprite helpers |
| `mascot.py` | The retro PC mascot sprite (green CRT face) |
| `palette.py` | The 16 RGBI colours, colour-space helpers, 8-bit BMP writer |
| `assets/logo_400.png` | StairwayToRetro logo, used by DEMO6 only |
| `scr/DEMO5.SCR`, `scr/DEMO6.SCR` | The compiler scripts, for reference. The Python scripts write identical copies next to the frames |

## Requirements

- Python 3 with NumPy, SciPy and Pillow. Tested with Python 3.13, NumPy 2.5,
  SciPy 1.18 and Pillow 13. `demo5.py` does not need Pillow.
- About 90 MB of free disk space for the generated frames (DEMO5: 1800 x 16 KB,
  DEMO6: 906 x 64 KB).
- `XDP_COMP.EXE`, run under DOS or in DOSBox. Build it from this repository
  (see the main README) or take it from the release zip.
- `XDP_PLAY.EXE` to watch the result.

No ffmpeg or other external tool is used.

```
pip install numpy scipy pillow
```

## 1. Generate the frames, the music and the scripts

From this folder:

```
python3 demo5.py
python3 demo6.py
```

Each script takes a few seconds and writes into `build/DEMO5/` or
`build/DEMO6/` (set the `OUT` environment variable to choose another folder):

- `F0000.BMP`, `F0001.BMP`, ...: one 8-bit BMP per frame, pixel values are
  the 16 RGBI colour indices
- `DEMO5.WAV` / `DEMO6.WAV`: 8-bit unsigned mono PCM at 11040 Hz
- `DEMO5.SCR` / `DEMO6.SCR`: the compiler script (`sourcefps`, `screenmode`,
  `waveinput`, then the frame list)

The output is deterministic: all random numbers come from fixed seeds, so the
files are byte-identical on every run.

### Why DEMO6 has a planning step

The player has to run each frame's change code within one frame period. In
320x200 mode a few frames (the two scene changes, at 21.3 s and 38.4 s)
change too much at once. `plan6.py` estimates the cost of every frame and,
when a frame is over budget (7800 bytes), sends only the part of the picture
that fits, worst-looking areas first, and finishes it on the next frame. In
the shipped clip this affects 2 changes, each spread over 2 frames. It also
adds 6 silent frames at the start (0.4 s) while the first full picture is
drawn.

## 2. Compile with XDP_COMP

Copy `XDP_COMP.EXE` into `build/DEMO5/` (or `build/DEMO6/`) and run it under
DOS, from that folder:

```
XDP_COMP DEMO5.SCR
XDP_COMP DEMO6.SCR
```

The file names are 8.3, so any DOS works. In DOSBox, mount the folder (with
long file names off) and run the compiler there, for example:

```
mount b /path/to/demo/build/DEMO5
b:
XDP_COMP DEMO5.SCR
```

The scripts set `debug=1`, so the compiler also writes `DEMO5.LOG` /
`DEMO6.LOG` with per-frame statistics. The result is `DEMO5.XDV` (2,788,616 bytes) and
`DEMO6.XDV` (3,414,922 bytes). With the XDP_COMP of release 0.1.0 they are
byte-identical to the clips in the release zip.

## 3. Play with XDP_PLAY

```
SET BLASTER=A220 I7 D1
XDP_PLAY DEMO5.XDV
XDP_PLAY DEMO6.XDV
```

- `DEMO5.XDV` (mode 5) plays on CGA, EGA or VGA. Data rate: 45 KB/s on
  average, 120 KB/s peak.
- `DEMO6.XDV` (mode 6) needs EGA or VGA. Data rate: 55 KB/s on average,
  90 KB/s peak.
- Both were made for an 8088 at 8 MHz (Atari PC2) with a Sound Blaster.
  `/NOSOUND` plays without a sound card. `/p` and `/r` skip the messages and
  the statistics; see the main README for all switches.

Copy the clips to a hard disk or CF card: floppies are too slow and too small.
